# Real-Time Delivery System

A real-time delivery platform with Android apps (Customer & Courier) and a Spring Boot backend.

## Features
- Real-time courier tracking via WebSockets
- Order management REST API
- Containerized with Docker

## Tech Stack
- **Backend:** Spring Boot 4.0.1, Java 17, PostgreSQL, Redis
- **Mobile:** Android (Kotlin), Jetpack Compose

## Quick Start
```bash
cd BE
docker-compose up --build -d
```

API available at: http://localhost:8080
